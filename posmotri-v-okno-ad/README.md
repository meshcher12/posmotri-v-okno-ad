# Посмотри в окно

Учебный фронтенд-проект: поиск городских видео, фильтрация по времени суток,
просмотр выбранного ролика и постраничная загрузка результатов.

## Запуск

Откройте `index.html` через локальный HTTP-сервер или используйте Live Server.
Приложение загружает данные с `https://v-content.practicum-team.ru`.
Для работы необходим доступ к этому API.

## Автотесты

Нужен Node.js 18 или новее. Установка зависимостей не требуется:

```bash
npm test
```

Тесты используют встроенный `node:test` и покрывают формирование запросов,
обработку ответов, фильтры, пагинацию и рендеринг карточек.
