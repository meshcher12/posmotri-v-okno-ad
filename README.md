# Посмотри в окно

Учебный фронтенд-проект: поиск городских видео по городу и времени суток,
просмотр выбранного ролика и постраничная навигация по локальному каталогу.

## Запуск

Откройте `index.html` через локальный HTTP-сервер, например Live Server.
Интернет-соединение и сервер API не нужны: каталог находится в
`scripts/videos.js`, а видео и постеры — в папке `media/`.

Чтобы добавить свой ролик, поместите видео и постер в `media/`, затем добавьте
запись в массив `VIDEOS` в `scripts/videos.js`. Для каждого видео укажите
уникальный `id`, город, описание, время суток (`morning`, `afternoon` или
`night`), путь к ролику и путь к постеру.

Макеты Figma, методичка PDF и локальные правила `.cursorrules` намеренно
исключены из репозитория.
